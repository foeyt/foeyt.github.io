Taylor 公式

Taylor 多项式

定理

  1. 带有 Peano 余项的 Taylor 多项式：设函数 f(x) 在 x0 有直到 n 阶的导数，在含点 x0 的区间 I 内一直有到 n − 1 阶的导数，则 I 上 f(x) 可以表示为： $$ f(x) = f(x_0) + f'(x_0)(x - x_0) + \frac{f''(x_0)}{2!}(x-x_0)^2 + \cdots + \frac{f^{(n)}(x)}{n!}(x-x_0)^n + R_n(x) $$ 其中余项 Rn(x) = o((x − x0)n), x → x0。

  2. 带有 Langrange 余项的 Taylor 多项式：设函数 f(x) 在区间 I 上有 n + 1 阶导数，x0 ∈ I，则对 ∀x ∈ I，f(x) 可以表示为： $$ f(x) = f(x_0) + f'(x_0)(x - x_0) + \frac{f''(x_0)}{2!}(x-x_0)^2 + \cdots + \frac{f^{(n)}(x)}{n!}(x-x_0)^n + R_n(x) $$ 其中余项 $R_n(x) = \frac{f^{(n + 1)}(\xi)}{(n+1)!}(x - x_0)^{n + 1},\; (x_0 - \xi)(x - \xi) < 0$。

注意：

  1. Taylor 公式是 Langrange 中值定理的推广。
  2. 在 Langrange 余项中，由于 ξ 介于 x0 和 x 之间，令 $\theta = \frac{\xi - x_0}{x - x_0},\; 0 < \theta < 1$，则 ξ = x0 + θ(x − x0)，改写 Langrange 余项为：$R_n(x) = \frac{f^{(n+1)}(x_0 + \theta(x - x_0))}{(n + 1)!}(x - x_0)^{n + 1}$。
  3. 取 x0 = 0 可以得到 Maclaurin 公式，常用来计算函数在 0 附近的近似值。

常见 Maclaurin 公式

$$ \begin{flalign} e^x &= 1 + x + \frac{1}{2!}x^2 + \cdots + \frac{1}{n!}x^n + R_n(x) \\ \sin x &= x - \frac{1}{3!}x^3 + \frac{1}{5!}x^5 - \cdots + (-1)^n \frac{1}{(2n + 1)!} x^{2n + 1} + R_{2n+2}(x) \\ \cos x &= 1 - \frac{1}{2!}x^2 + \frac{1}{4!}x^4 - \cdots + (-1)^n\frac{1}{(2n)!}x^{2n} + R_{2n+1}(x) \\ \ln(1+x) &= x - \frac{1}{2}x^2 + \frac{1}{3}x^3 - \cdots + (-1)^n\frac{1}{n + 1}x^{n + 1} + R_{n + 1}(x) \\ \frac{1}{1-x} &= 1 + x + x^2 + \cdots + x^n + R_n(x) \\ \frac{1}{1+x} &= 1 - x + x^2 - \cdots + (-1)^nx^n + R_n(x) \\ (1+x)^\alpha &= 1 + \alpha x + \frac{\alpha(\alpha - 1)}{2!}x^2 + \cdots + \frac{\alpha(\alpha-1)\cdots(\alpha-n+1)}{n!}x^n + R_{n+1}(x) \\ \arctan x &= x - \frac{1}{3}x^3 + \frac{1}{5}x^5 - \cdots + (-1)^n\frac{1}{2n+1}x^{2n+1} + R_{2n+2}(x) \\ \arcsin x &= x + \frac{1}{6}x^3 + \frac{3}{40}x^5 + \cdots \\ \tan x &= x + \frac{1}{3}x^3 + \frac{2}{15}x^5 + \cdots \end{flalign} $$

Taylor 公式的应用

近似计算

取： $$ f(x) \approx f(x_0) + f'(x_0)(x - x_0) + \frac{f''(x_0)}{2!}(x-x_0)^2 + \cdots + \frac{f^{(n)}(x)}{n!}(x-x_0)^n $$ 根据 Langrange 余项，精确度 ϵ 满足 $\frac{M|x_1 - x_0|^{n+1}}{(n+1)!} < \epsilon$，其中 M 是 |f(n + 1)(x)| 在包含 x0 与 x1 的函数的上界。

例题

计算 e 的值，使其误差不超过 10−5。

Solve： $$ e = 1 + 1 + \frac{1}{2!} + \cdots + \frac{1}{n!} + \frac{e^\xi}{(n+1)!},\; 0 < \xi < 1 $$ 而 $\frac{e^\xi}{(n+1)!} < \frac{e}{(n+1)!} < \frac{3}{(n+1)!} < 10^{-5}$，解得 n = 9。

$e = 1 + \cdots + \frac{1}{9!} \approx 2.718282$。

计算极限

例题

$\lim\limits_{x\to 0} \frac{24 - 12x^2 + x^4 - 24\cos x}{\sin^6 x}$

Solve： $$ \begin{align} &\lim\limits_{x\to 0} \frac{24 - 12x^2 + x^4 - 24\cos x}{\sin^6 x} \\ &= \lim\limits_{x\to 0} \frac{24-12x^2+x^4 - 24(1-\frac{1}{2}x^2+\frac{1}{24}x^4-\frac{1}{720}x^6+o(x^6))}{x^6} \\ &= \lim\limits_{x\to 0} \frac{\frac{1}{30}x^6 + o(x^6)}{x^6} = \frac{1}{30} \end{align} $$

微分学的应用

单调性与极值

定理

  1. 设函数 f(x) 在 (a, b) 内可导，如果在 (a, b) 内 f′(x) > 0（或 f′(x) < 0），则函数 f(x) 在 (a, b) 上严格单调增（或严格单调减）。
  2. 若函数 f(x) 在 x0 的邻域 |x − x0| < δ 内连续，在去心邻域 0 < |x − x0| < δ 内可导，那么：
    • 当 x ∈ (x0 − δ, x0) 时，f′(x) > 0，而当 x ∈ (x0, x0 + δ) 时，f′(x) < 0，则 x0 是函数的一个极大值点，f(x0) 是函数的一个极大值。
    • 当 x ∈ (x0 − δ, x0) 时，f′(x) < 0，而当 x ∈ (x0, x0 + δ) 时，f′(x) > 0，则 x0 是函数的一个极小值点，f(x0) 是函数的一个极小值。
    • 当 f′(x) 在 x0 两侧保持同一符号时，x0 不是 f(x) 的极值点，f(x0) 不是 f(x) 的极值。
  3. 设函数 f(x) 在点 x0 处满足 f′(x0) = 0，f″(x) ≠ 0。
    • 若 f″(x0) < 0，则 x0 是极大值点。
    • 若 f″(x0) > 0，则 x0 是极小值点。

注意：当 f′(x) ≥ 0 或 f′(x) ≤ 0 而 f′(x) = 0 的点个数有限，认为 f(x) 严格单调递增或递减。

凹凸性与渐近线

凸函数与凹函数

定义

  • 若 f(x) 在 I 上连续，∀x1, x2 ∈ I，都有 $f(\frac{x_1 + x_2}{2}) < \frac{f(x_1) + f(x_2)}{2}$。则称 f(x) 是区间 I 上的凸函数。

  • 若 f(x) 在 I 上连续，∀x1, x2 ∈ I，都有 $f(\frac{x_1 + x_2}{2}) > \frac{f(x_1) + f(x_2)}{2}$。则称 f(x) 是区间 I 上的凹函数。

注意：凹凸函数的图像正好与汉字字形相反。

定理

  • 设 f(x) 在 I 上可导，并且 f′(x) 在区间内严格单调增，则 f(x) 在 I 上是凸函数。
  • 设 f(x) 在 I 上二阶可导，∀x ∈ I，都有 f″(x) > 0，则 f(x) 在 I 上是凸函数。

定理

Jensen 不等式：对于区间 I 上的凸函数 f(x)。

  1. ∀x1, x2 ∈ I, ∀0 < λ < 1, x1 ≠ x2 f(λx1 + (1 − λ)x2) < λf(x1) + (1 − λ)f(x2)

  2. $\forall x_i \in I, \forall 0 < \lambda_i < 1, x_i \neq x_j, \sum_{i=1}^n \lambda_i = 1$ $$ f(\sum_{i=1}^n\lambda_ix_i) < \sum_{i=1}^nf(\lambda_ix_i) $$

  3. ∀x1, x2, x ∈ I, x1 < x < x2 $$ \frac{f(x) - f(x_1)}{x - x_1} < \frac{f(x_2) - f(x_1)}{x_2 - x_1} < \frac{f(x_2) - f(x)}{x_2 - x} $$

注意：Jensen 不等式可能在某些题目中用到。

拐点

定义

设 f(x) 在包含 x0 的区间 I 上连续，点 x0 是 f(x) 的凹凸区间的分界点，则称曲线上的点 (x0, f(x0)) 是曲线 y = f(x) 的一个拐点。

注意拐点是点，而零点、极值点不是点。

定理

设 f(x) 在 x0 处连续，在 x0 的一个去心邻域内二阶可导，且在 x0 两侧二阶导数异号，则 (x0, f(x0)) 是曲线 y = f(x) 的一个拐点。特别地，当 f(x) 在 x0 的二阶导数存在时，点 (x0, f(x0)) 是曲线的拐点当且仅当 f″(x0) = 0。

渐近线

定理

  • 垂直渐近线：若函数 f(x) 满足 $\lim\limits_{x\to x_0} = \infty$，或 $\lim\limits_{x\to x_0^-} = \infty$，$\lim\limits_{x\to x_0^+} = \infty$，则称直线 x = x0 是曲线 y = f(x) 的垂直渐近线。
  • 水平渐近线：若函数 f(x) 满足 $\lim\limits_{x\to \infty} = a$，或 $\lim\limits_{x\to -\infty} = a$，$\lim\limits_{x\to +\infty} = a$，则称直线 y = a 是曲线 y = f(x) 的水平渐近线。
  • 斜渐近线：若对于 0 ≠ a ∈ ℝ，函数 f(x) 满足 $\lim\limits_{x \to \infty} \frac{f(x)}{x} = a,\; \lim\limits_{x \to \infty} (f(x) - ax) = b$，则称直线 y = ax + b 是曲线 y = f(x) 的斜渐近线。

曲率

定义

平均曲率：弧长为 σ 的一段弧 $\overset{\LARGE{\frown}}{AB}$，其转过的角度为 φ，圆弧的平均弯曲程度为 $\frac{\varphi}{\sigma}$，记作平均曲率。

点的曲率：极限 $\lim\limits_{\sigma \to 0} \frac{\varphi}{\sigma}$ 存在，其值表示在某一点的曲率。

函数的曲率计算：

  • 设曲线 y = f(x)，且二阶可导，某一段弧长为 Δs，过某一点倾斜角为 α，这段弧转过的角度为 Δα，故这点的曲率为 $\lim\limits_{\Delta s \to 0}\left|\frac{\Delta \alpha}{\Delta s}\right| = \frac{\mathrm{d}\alpha}{\mathrm{d}s}$。

  • 由上述得到，曲率对应的函数为： $$ k = \frac{|y''|}{(1 + y')^{\frac{3}{2}}} $$

  • 注意：若曲线由参数方程 x = φ(t), y = ψ(t) 表示，则： $$ k = \frac{|\varphi'(t)\psi''(t) - \varphi''(t)\psi'(t)|}{((\varphi'(t))^2 + (\psi'(t))^2)^{\frac{3}{2}}} $$

定义

曲率圆，曲率半径：曲线 y = f(x) 上某一点 A 的曲率 k ≠ 0，过这个点作曲线的法线，在曲线凹的一侧取点 C，以 C 为圆心，$|AC| = \frac{1}{k}$ 为半径画圆，这个圆就是曲线在点 A 的曲率圆，半径就是曲率半径。

不定积分的概念和性质

不定积分的定义

定义

  1. 原函数：区间 I 上，可导函数 F(x) 的导函数为 f(x)，即对于 ∀x ∈ I，都有 F′(x) = f(x)，则 F(x) 为 f(x) 在区间上的一个原函数。

  2. 不定积分：称 f(x) 在区间 I 上的全体原函数 {F(x) + C} 为函数 f(x) 在区间上的不定积分，记为： ∫f(x)dx = F(x) + C

（记忆）基本积分公式表

基本版： $$ \begin{align} &\int k\mathrm{d}x = kx + C \\ &\int x^\alpha \mathrm{d}x = \frac{1}{\alpha + 1}x^{\alpha + 1} + C,\; \alpha \neq -1 \\ &\int \frac{1}{x} \mathrm{d}x = \ln |x| + C \\ &\int \sin x \mathrm{d}x = -\cos x + C \\ &\int \cos x \mathrm{d}x = \sin x + C \\ &\int \tan x \mathrm{d}x = -\ln|\cos x| + C \\ &\int \frac{1}{\cos^2 x} \mathrm{d}x = \tan x + C \\ &\int \frac{1}{\sin^2x} \mathrm{d}x = -\cot x + C \\ &\int a^x \mathrm{d}x = \frac{a^x}{\ln a} + C \\ &\int e^x \mathrm{d}x = e^x + C \\ &\int \frac{1}{1 + x^2} \mathrm{d}x = \arctan x + C \\ &\int \frac{1}{\sqrt{1 - x^2}} \mathrm{d}x = \arcsin x + C \\ &\int \cosh x = \sinh x + C \\ &\int \sinh x = \cosh x + C \\ &\int \sec x \tan x \mathrm{d}x = \sec x + C \\ &\int \csc x \cot x \mathrm{d}x = -\csc x + C \\ \end{align} $$ 复杂版： $$ \begin{align} &\int \frac{1}{\sqrt{A^2 + x^2}} \mathrm{d}x = \ln |x + \sqrt{A^2 + x^2}| + C \\ &\int \frac{1}{\sqrt{x^2 - A^2}} \mathrm{d}x = \ln |x + \sqrt{x^2 - A^2}| + C \\ &\int \frac{1}{\sqrt{A^2 - x^2}} \mathrm{d}x = \arcsin \frac{x}{A} + C \\ &\int \frac{1}{x^2 - A^2} \mathrm{d}x = \frac{1}{2A} \ln \left|\frac{x - A}{x + A}\right| + C \\ &\int \frac{1}{x^2 + A^2} \mathrm{d}x = \frac{1}{A} \arctan \frac{x}{A} + C \\ &\int \sqrt{A^2 + x^2} \mathrm{d}x = \frac{A^2}{2}\ln(x + \sqrt{x^2 + A}) + \frac{1}{2}x\sqrt{x^2 + A^2} + C \\ &\int \sqrt{A^2 - x^2} \mathrm {d}x = \frac{A^2}{2} \arcsin \frac{x}{A} + \frac{1}{2}x\sqrt{A^2 - x^2} + C \\ &\int \frac{1}{\sin x} \mathrm{d}x = \ln |\tan \frac{x}{2}| + C = \ln |\csc x - \cot x| + C \\ &\int \frac{1}{\cos x} \mathrm{d}x = \ln |\tan \frac{x + \frac{\pi}{2}}{2}| + C = \ln |\sec x + \tan x| + C \end{align} $$

(选读) 一些复杂的计算过程

  1. $\int \frac{1}{\sqrt{A^2 + x^2}} \mathrm{d}x$ 的计算：

    令 x = Asinh θ $$ \begin{align} &\int \frac{1}{\sqrt{A^2 + x^2}} \mathrm{d}x = A\int \frac{1}{A\cosh \theta} \cosh \theta \mathrm{d}\theta = \theta + C = \mathrm{arsinh} \frac{x}{A} + C \\ &= \ln |\frac{x}{A} + \sqrt{\frac{x^2}{A^2} + 1}| + C = \ln |x + \sqrt{x^2 + A}| + C \end{align} $$

  2. $\int \frac{1}{\sqrt{A^2 - x^2}} \mathrm{d}x$ 的计算：

    令 x = Asin θ $$ \begin{align} \int \frac{1}{\sqrt{A^2 - x^2}} \mathrm{d}x = A\int \frac{1}{A\cos\theta} \cos\theta \mathrm{d}\theta = \theta + C = \arcsin \frac{x}{A} + C \end{align} $$

  3. $\int \frac{1}{x^2 - A^2} \mathrm{d}x$ 的计算：

    令 x = Asin θ $$ \begin{align} &\int \frac{1}{x^2 - A^2} \mathrm{d}x = A \int \frac{1}{-A^2\cos^2\theta}\cos\theta \mathrm{d}\theta = -\int \frac{1}{A\cos\theta} \mathrm{d}\theta = -\frac{1}{A}\ln|\sec \theta + \tan \theta| + C \\ &= -\frac{1}{A} \ln \left|\frac{A + x}{\sqrt{A^2 - x^2}}\right| + C = \frac{1}{A}\ln \left|\sqrt{\frac{x - A}{x + A}}\right| + C = \frac{1}{2A} \ln \left|\frac{x-A}{x+A}\right| + C \end{align} $$

  4. $\int \frac{1}{x^2 + A^2} \mathrm{d}x$ 的计算： $$ \int \frac{1}{x^2 + A^2} \mathrm{d}x = \frac{1}{A} \int \frac{1}{1 + \frac{x^2}{A^2}} \mathrm{d}{\frac{x}{A}} = \frac{1}{A} \arctan \frac{x}{A} + C $$

  5. $\int \sqrt{A^2 + x^2} \mathrm{d}x$ 的计算：

    令 x = Asinh θ $$ \begin{align} &\int \sqrt{A^2 + x^2} \mathrm{d}x = A^2 \int \cosh^2\theta \mathrm{d}\theta = A^2 \int \frac{1 + \cosh 2\theta}{2} \mathrm{d}\theta \\ &= \frac{A^2}{2}\theta + \frac{A^2}{4}\sinh 2\theta + C = \frac{A^2}{2} \mathrm{arsinh}\frac{x}{A} + \frac{A}{2}x\cosh(\mathrm{arsin}\frac{x}{A}) + C \\ &= \frac{A^2}{2}\ln |x + \sqrt{x^2 + A^2}| + \frac{1}{2}x\sqrt{x^2 + A^2} + C \end{align} $$ 注意：就像三角形里面，一个直角边是 a，斜边是 c，另一个直角边是 $b = \sqrt{c^2 - a^2}$，在双曲三角里面也有类似的勾股定理，只不过另一个直角边要换成 $b = \sqrt{c^2 + a^2}$。即正常三角：a2 + b2 = c2，双曲三角：|a2 − b2| = c2。

  6. $\int \sqrt{A^2 - x^2} \mathrm {d}x$ 的计算：

    令 x = Asin θ $$ \begin{align} &\int \sqrt{A^2 - x^2} \mathrm {d}x = A^2 \int\cos^2\theta\mathrm{d}\theta = \frac{A^2}{2}\int 1 + \cos2\theta \mathrm{d}\theta \\ &= \frac{A^2}{2}\theta + \frac{A^2}{4}\sin2\theta + C = \frac{A^2}{2}\arcsin\frac{x}{A} + \frac{A}{2}x\cos(\arcsin\frac{x}{A}) + C \\ &= \frac{A^2}{2}\arcsin\frac{x}{A} + \frac{1}{2}x\sqrt{A^2-x^2} + C \end{align} $$

  7. $\int \frac{1}{\sin x} \mathrm{d}x$ 的计算： $$ \begin{align} &\int \frac{1}{\sin x} \mathrm{d}x = \int \frac{\cos\frac{x}{2}}{\sin\frac{x}{2}\cos\frac{x}{2}}\frac{1}{\cos\frac{x}{2}}\mathrm{d}{\frac{x}{2}} = \int \frac{1}{\tan\frac{x}{2}}\mathrm{d}{\tan\frac{x}{2}} = \ln |\tan\frac{x}{2}| + C \\ &= \ln \left|\frac{1 - \cos x}{\sin x}\right| + C = \ln |\csc x - \cot x| + C \end{align} $$

不定积分的性质

  1. 不定积分的微分：d(∫f(x)dx) = f(x)dx
  2. 原函数的微分的不定积分与原函数的关系：∫dF(x) = F(x) + C
  3. 线性性：∫(k1f1(x) + k2f2(x))dx = k1∫f1(x)dx + k2∫f2dx

原函数的拼接

部分下情况下要对不定积分的结果在不同区间上的结果进行拼接，成为 ℝ 上的函数。

举例： $$ \int \frac{1 + x^2}{1 + x^4} \mathrm{d}x = \left\{\begin{matrix} \frac{1}{\sqrt{2}}\arctan \frac{\sqrt{2}x}{1-x^2} + c_1, x < -1 \\ 0, x = -1\\ \frac{1}{\sqrt{2}}\arctan \frac{\sqrt{2}x}{1-x^2}, -1 < x < 1\\ 0, x = 1\\ \frac{1}{\sqrt{2}}\arctan \frac{\sqrt{2}x}{1-x^2} + c_2, x > 1 \end{matrix}\right.\;\;\; +C $$

不定积分的计算方法

换元法

第一积分换元法

定理

设 g(t) 在区间 J 上有原函数 G(t)，函数 t = φ(x) 在区间 I 上可导，且把区间 I 一一映射成 J，记 f(x) = g(φ(x)) ⋅ φ′(x), x ∈ I，则 F(x) = G(φ(x))，即 ∫f(x)dx = ∫g(φ(x))φ′(x)dx = ∫g(t)dt = G(t) + C = F(x) + C

即从 f(x) 中拆出来一个函数的导数，放在 d 后面。

第二积分换元法

定理

设 x = φ(t) 在区间 J 上可导且 φ′(t) ≠ 0，φ 将 J 一一映射成 I，若 g(t) = f(φ(t))φ′(t) 在 J 上有原函数 G(t)，则 f(x) 在 I 上有原函数 F(x) = G(φ−1(x))，其中 t = φ−1(x) 是反函数，即 ∫f(x)dx = ∫f(φ(t))φ′(t)dt = ∫g(t)dt = G(t) + C = F(x) + C

即用一个新的变元全面代替 x，包括 d 后面的。

常利用三角换元法和双曲三角换元法解决问题，下面给出双曲三角的一些公式： $$ \begin{align} &\cosh^2x - \sinh^2x = 1 \\ &\cosh^2x + \sinh^2x = \cosh2x \\ &\sinh(x\pm y) = \sinh x\cosh y \pm \cosh x\sinh y \\ &\cosh(x\pm y) = \cosh x\cosh y \pm \sinh x\sinh y \\ &\tanh(x\pm y) = \frac{\tanh x \pm \tanh y}{1 \pm \tanh x\tanh y} \\ &\cosh2x = 2\cosh^2x - 1 = 1 - \sinh^2x \\ &(\sinh x)' = \cosh x \\ &(\cosh x)' = \sinh x \\ &\mathrm{arsinh}\,x = \ln(x+\sqrt{x^2+1}) \\ &\mathrm{arcosh}\,x = \ln(x+\sqrt{x^2-1}) \\ &\mathrm{artanh}\,x = \frac{1}{2}\ln\frac{1+x}{1-x} \end{align} $$

分部积分法

定理

设 u(x) 和 v(x) 可导，不定积分 ∫v(x)du(x) 存在，则 ∫u(x)dv(x) 也存在，且 ∫u(x)dv(x) = u(x)v(x) − ∫v(x)du(x)

注意：d 右边的 x 有时也可以当作一个函数，参与分部积分。

三角函数有理式的积分

三角函数有理式一般记作 R(sin x, cos x)。

  1. 万能代换（Weierstrass 代换） $$ \sin x = \frac{2\tan \frac{x}{2}}{1 + \tan^2\frac{x}{2}}\;\;\;\; \cos x = \frac{1 - \tan^2\frac{x}{2}}{1 + \tan^2\frac{x}{2}}\;\;\;\; \tan x = \frac{2\tan \frac{x}{2}}{1 - \tan^2\frac{x}{2}} $$ 一般计算量较大且会提高次数，一般尽量不用万能代换。

  2. 三类特殊变换

    • 当 R(−sin x, cos x) = −R(sin x, cos x)，即对于 sin x 是奇函数时，令 t = cos x
    • 当 R(sin x, −cos x) = −R(sin x, cos x)，即对于 cos x 是奇函数时，令 t = sin x
    • 当 R(−sin x, −cos x) = R(sin x, cos x)，即对于 sin x, cos x 是偶函数时，令 t = tan x

    这三类变换能够显著提高运算速度。

简单根式的有理式的积分

  1. 针对第一类，令 $t = \sqrt[n]{\frac{ax+b}{cx+d}}$，得到 x，脱去根号。
  2. 针对第二类，使用 Euler 代换：
    • a > 0，第一 Euler 代换：$\sqrt{ax^2+bx+c} = t \pm \sqrt{a}x$

    • 当 ax2 + bx + c = a(x − λ)(x − μ)，第三 Euler 代换：$\sqrt{ax^2+bx+c} = t(x-\lambda)$

另一类根式代换 $t = \sqrt[n]{x}$ 或 $t = \sqrt{e^x \pm 1}$ 或 $t = e^{-\frac{x}{2}}$。

定积分的概念

定积分的 Riemann 和定义（Riemann 积分）

定义

设函数 f(x) 在区间 [a, b] 内有定义，在 [a, b] 内任意插入 n − 1 个分点，记为 a = x0 < x1 < ⋯ < xn − 1 < xn = b 称其为 [a, b] 上的一个分割 T。其中 Δxi = xi − xi − 1，记 λ(T) = max {Δx1, ⋯, Δxn}。在每个分割子区间内取 ξi ∈ [xi − 1, xi]，求和： $$ \sigma(a, b, f; T, \xi_1, \cdots, \xi_n) = \sum_{i=1}^n f(\xi_i)\Delta x_i $$ 这个求和称为积分和，与分割 T 有关，与 ξi 的取法有关，简记为 ξ(T, ξi)。 $$ \lim\limits_{\lambda(T)\to 0^+} \sigma(T, \xi_i) $$ 若极限存在，且与 T，ξi 无关，则 f(x) 在区间 [a, b] 上可积，并称此极限为函数 f(x) 在区间 [a, b] 上的定积分，记作： $$ \int_a^b f(x)\mathrm{d}x = \lim\limits_{\lambda(T)\to 0^+}\sum_{i=1}^n f(\xi_i)\Delta x_i $$

常见分割形式：在区间 [a, b] 上等距分割 $x_i = a + \frac{b-a}{n}i$，等比分割 $x_i = a(\sqrt[n]{\frac{b}{a}})^i$。

可积性的判定

定理

可积的必要条件：若函数 f(x) 在 [a, b] 上可积，则它在 [a, b] 上有界。

这一定理可以简述为：可积一定有界，有界不一定可积；无界一定不可积。有界却不可积的函数举例 Dirichlet 函数和 Riemann 函数这两类病态函数。

定义

Darboux 和：设 f(x) 在 [a, b] 上有界，它在 [a, b] 上的上确界为 M，下确界为 m。对于 [a, b] 上的一个分割 T，记 f(x) 在每个小区间 [xi − 1, xi] 上的上确界和下确界为 Mi, mi。

  • Darboux 上和：$S(T) = \sum_{i=1}^nM_i\Delta x_i$
  • Darboux 下和：$s(T) = \sum_{i=1}^n m_i\Delta x_i$

Darboux 和有以下性质：

  1. 对区间 [a, b] 的任意一个确定的分割 T，所有的积分和 σ(T) 介于该分法的上和与下和之间，即：s(T) ≤ σ(T) ≤ S(T)。
  2. 对区间 [a, b] 的任意一个确定的分割 T，上和与下和分别是所有积分和 σ(T, ξi) 的上确界与下确界，即：S(T) = supξi{σ(T, ξi)}，s(t) = infξi{σ(T, ξi)}。
  3. 对区间 [a, b] 的所有可能的分割 T，下和的上确界不超过上和的下确界，即：l = sup s(T) ≤ inf S(T) = L。

定理

定积分存在的判别准则：设函数 f(x) 在区间 [a, b] 上有界，则它在该区间上可积的充要条件是：$\lim\limits_{\lambda(T)\to 0^+}(S(T) - s(T)) = 0$。

若记 M 和 m 分别是有界函数 f(x) 在 [a, b] 上的上下确界，则 ω = M − m 是 f(x) 在 [a, b] 上的振幅。于是 Darboux 上和与下和的差可以化为 $S(T) - s(T) = \sum_{i=1}^n \omega_i\Delta x_i$。

该判别准则又可记为：设函数 𝑓(𝑥) 在区间 [𝑎,𝑏] 上有界，则它在该区间上可积的充要条件是：$\lim\limits_{\lambda(T)\to 0^+}\sum_{i=1}^n \omega_i\Delta x_i = 0$

可积函数类：

  • 在区间 [a, b] 上一致连续的函数一定可积。
  • 在区间 [a, b] 上的有界函数只有有限多个间断点则函数可积。
  • 在区间 [a, b] 上有界的单调函数一定可积。

Riemann 和的应用

利用定义计算积分

例题

利用定义计算 $\int_0^\frac{\pi}{2} \sin x \mathrm{d}x$

Solve：

取分割 $x_i = \frac{\pi}{2n}i$，且 $0 \leq x_i \leq \frac{\pi}{2}$，取 $\xi_i = x_i = \frac{\pi}{2n}i$，$\Delta x_i = \frac{\pi}{2n}$ $$ \int_0^\frac{\pi}{2}\sin x \mathrm{d}x = \lim\limits_{n \to \infty}\sum_{i=1}^n \sin\xi_i \Delta x_i = \lim\limits_{n \to \infty}\frac{\pi\sum_{i=1}^n\sin{\frac{\pi}{2n}i}}{2n} $$ 下面化简 $\sum_{i=1}^n\sin\frac{\pi}{2n}i$。 $$ \begin{align} &\sum_{i=1}^n\sin\frac{\pi}{2n}i = \frac{1}{2\sin\frac{\pi}{4n}}\sum_{i=1}^n2\sin\frac{\pi}{2n}\sin\frac{\pi}{4n} \\ &= \frac{1}{2\sin\frac{\pi}{4n}}\sum_{i=1}^n(\cos\frac{\pi(2i-1)}{4n}-\cos\frac{\pi(2i+1)}{4n}) \\ &= \frac{1}{2\sin\frac{\pi}{4n}}(\cos\frac{\pi}{4n} - \cos\frac{\pi(2n+1)}{4n}) \end{align} $$

$$ \lim\limits_{n\to\infty}\frac{\pi}{2n}\sum_{i=1}^n\sin{\frac{\pi}{2n}i} = \lim\limits_{n\to\infty}\frac{\pi}{4n\sin\frac{\pi}{4n}}(\cos\frac{\pi}{4n}-\cos\frac{\pi(2n+1)}{4n}) = 1 $$

故 $\int_0^\frac{\pi}{2} \sin x\mathrm{d}x= 1$

利用定义计算极限

例题

计算：$\lim\limits_{n\to \infty}(\frac{1}{\sqrt{n^2}} + \frac{1}{\sqrt{n^2-1}} + \cdots + \frac{1}{\sqrt{n^2-(n-1)^2}})$

Solve： $$ \lim\limits_{n\to \infty}(\frac{1}{\sqrt{n^2}} + \frac{1}{\sqrt{n^2-1}} + \cdots + \frac{1}{\sqrt{n^2-(n-1)^2}}) = \lim\limits_{n\to \infty}\frac{1}{n}\sum_{i=1}^{n}\frac{1}{\sqrt{1-(\frac{i-1}{n})^2}} $$ 取 $f(x) = \frac{1}{\sqrt{1-x^2}}$，在区间 [0, 1] 上定义分割 $x_i = \frac{1}{n}$，取 $\xi_i = x_{i-1} = \frac{i-1}{n}$，则化为： $$ \lim\limits_{n\to \infty}\frac{1}{n}\sum_{i=1}^{n}\frac{1}{\sqrt{1-(\frac{i-1}{n})^2}} = \lim\limits_{n\to \infty}\sum_{i=1}^nf(\xi_i)\Delta x_i = \int_0^1 \frac{1}{\sqrt{1-x^2}}\mathrm{d}x = \arcsin x\Big|^1_0 = \frac{\pi}{2} $$

定积分的基本性质和微积分基本定理

定积分的基本性质

  1. 线性性：

    对 [a, b] 上可积函数 f(x), g(x)，任意常数 c1, c2 有： ∫ab(c1f(x) + c2g(x))dx = c1∫abf(x)dx + c2∫abg(x)dx

  2. 积分区间可加性：

    1. 设 c ∈ (a, b)，f(x) 在 [a, b] 上可积，则 f(x) 在区间 [a, c], [c, b] 上也可积，且 ∫abf(x)dx = ∫acf(x)dx + ∫cbf(x)dx

    2. 若 f(x) 在 [a, b] 上可积，则它在任何一个子区间 [a1, b1] 上也是可积的，其中 a ≤ a1 < b1 ≤ b。

    3. 设 a < c < b，f(x) 在 [a, c] 和 [c, b] 上都可积，那么在 [a, b] 上也是可积的，并且 ∫abf(x)dx = ∫acf(x)dx + ∫cbf(x)dx

    4. 如果改变可积函数在积分区间上一点的值，则函数在此区间上的可积性和定积分值不会改变。

    5. 如果区间 [a, b] 被分为有限个子区间，并且 f(x) 在每个子区间上是可积的，则它在整个区间 [a, b] 也是可积的，它在整个区间 [a, b] 上的定积分等于各个子区间上定积分之和。

    6. 如果改变可积函数在积分区间上有限个点的值，则函数在此区间上的可积性及定积分值不会改变。

    7. 若 f(x) 在 [α, β] 上可积，∀a, b, c ∈ [α, β]，则有 ∫abf(x)dx = ∫acf(x)dx + ∫cbf(x)dx

积分不等式与积分中值定理

  1. 保序性：若在 [a, b] 上有 f(x) ≥ g(x)，则 ∫abf(x)dx ≥ ∫abg(x)dx。

  2. 若 f(x) 在 [a, b] 上连续，且 f(x) ≥ 0，但是 f(x) ≠ 0，则有 ∫abf(x)dx > 0。

  3. 若在 [a, b] 上 f(x) 与 g(x) 都连续，且 f(x) ≥ g(x)，但是 f(x) ≠ g(x)，则有 ∫abf(x)dx > ∫abg(x)dx。

  4. 估值公式：设 f(x) 在 [a, b] 上可积，且 m ≤ f(x) ≤ M，则有 m(b − a) ≤ ∫abf(x)dx ≤ M(b − a)。

  5. 绝对可积性：设 f(x) 在 [a, b] 上可积，则 |f(x)| 也在 [a, b] 上可积，并且|∫abf(x)dx| ≤ ∫ab|f(x)|dx，这类似于一个连续的三角不等式。

  6. 积分中值定理：设 f(x) 在闭区间 [a, b] 上连续，则至少存在一点 ξ ∈ (a, b)，使得 ∫abf(x)dx = f(ξ)(b − a)    (a < ξ < b)

  7. 第一积分中值定理：设 f(x) 在闭区间 [a, b] 上连续，φ(x) 可积且不变号，则至少存在一点 ξ ∈ (a, b)，使得 ∫abf(x)φ(x)dx = f(ξ)∫abφ(x)dx

微积分基本定理

定义

积分上限函数：若 f(x) 在 [a, b] 上可积，则对 [a, b] 上的任意一点 x，都对应唯一的一个定积分值 ∫axf(t)dt，则有函数 Φ(x) = ∫axf(t)dt 称为积分上限函数或者变上限函数。

定理

  1. 若函数 f(x) 在 [a, b] 上可积，则其积分上限函数 Φ(x) 在区间 [a, b] 上连续。

  2. 若函数 f(x) 在 [a, b] 上可积，在点 x ∈ [a, b] 处连续，则其积分上限函数 Φ(x) 在点 x ∈ [a, b] 处可导，且 $$ \Phi'(x) = \frac{\mathrm{d}}{\mathrm{d}x}\int_a^xf(t)\mathrm{d}t = f(x) $$

定理

微积分基本定理：设函数 f(x) 在区间 [a, b] 上连续，则有 $$ \frac{\mathrm{d}}{\mathrm{d}x}\int_{x_0}^x f(t)\mathrm{d}t = f(x)\;\; (a \leq x \leq b) $$ 其中 x0 ∈ [a, b] 是任意固定的一点。

注意：这里能够使用复合函数求导的链式法则： $$ \frac{\mathrm{d}}{\mathrm{d}x}\int_{v(x)}^{u(x)}f(t)\mathrm{d}t = \frac{\mathrm{d}}{\mathrm{d}x}\int_{x_0}^{u(x)}f(t)\mathrm{d}t - \frac{\mathrm{d}}{\mathrm{d}x}\int_{x_0}^{v(x)}f(t)\mathrm{d}t = f(u(x))u'(x) - f(v(x))v'(x) $$

定理

Newton-Leibniz 公式：设函数 f(x) 在区间 [a, b] 上连续，F(x) 是 f(x) 在 [a, b] 上的任意一个原函数，则有 ∫abf(x)dx = F(x)|ab = F(b) − F(a)

定积分的极限与求导

例题

证明：若函数 f(x) 是区间 [a, b] 上的连续正值函数，则： $$ e^{\frac{1}{b-a}\int_a^b\ln f(x)\mathrm{d}x} \leq \frac{1}{b-a}\int_a^bf(x)\mathrm{d}x $$

Prove：

利用 Jensen 不等式：ln x 是凹函数，则 $\ln(\frac{x_1+x_2}{2}) > \frac{\ln x_1 + \ln x_2}{2}$，则推广有： $$ \ln(\frac{1}{n}\sum_{i=1}^nf(\xi_i)) \geq \frac{\sum_{i=1}^n\ln f(\xi_i)}{n} $$ 这里取分割 $x_i = a + \frac{b-a}{n}i$，$\Delta x_i = \frac{b-a}{n}$，$\xi_i = x_i = a + \frac{b-a}{n}i$ 即可。

两边取极限，由极限的保号性得到： $$ \ln(\frac{1}{b-a}\lim\limits_{n\to\infty}\sum_{i=1}^nf(\xi_i)\Delta x_i) \geq \frac{1}{b-a}\lim\limits_{n\to\infty}\sum_{i=1}^n\ln f(\xi_i)\Delta x_i $$

$$ \ln(\frac{1}{b-a}\int_a^bf(x)\mathrm{d}x) \geq \frac{1}{b-a}\int_a^b\ln f(x)\mathrm{d}x $$

则有：

$$ e^{\frac{1}{b-a}\int_a^b\ln f(x)\mathrm{d}x} \leq e^{\ln(\frac{1}{b-a}\int_a^bf(x)\mathrm{d}x)} = \frac{1}{b-a}\int_a^bf(x)\mathrm{d}x $$

例题

$\lim\limits_{n\to\infty}\int_n^{n+p}\frac{\sin x}{x}\mathrm{d}x\;\; (p>0)$

Solve:

这是一个病态积分，不能直接求解，利用积分中值定理即可。

∃ξ ∈ (n, n + p)，使得 $\int_n^{n+p}\frac{\sin x}{x}\mathrm{d}x = p\frac{\sin\xi}{\xi}$。且 n → ∞, n + p → ∞，故 ξ → ∞。 $$ \lim\limits_{n\to\infty}\int_n^{n+p}\frac{\sin x}{x}\mathrm{d}x = p\lim\limits_{\xi\to\infty}\frac{\sin\xi}{\xi}\mathrm{d}x $$ 而 −1 ≤ sin ξ ≤ 1，故 $-\frac{1}{\xi} \leq \frac{\sin\xi}{\xi} \leq \frac{1}{\xi}$，故 $\lim\limits_{\xi\to\infty}\frac{\sin\xi}{\xi} = 0$。

故 $\lim\limits_{n\to\infty}\int_n^{n+p}\frac{\sin x}{x}\mathrm{d}x = 0$。

例题

$\frac{\mathrm{d}}{\mathrm{d}x}\int_a^b\frac{1}{\sqrt{1+x^2}}\mathrm{d}x$，$\frac{\mathrm{d}}{\mathrm{d}x}\int_{\sqrt{\ln x}}^x e^{-t^2}\mathrm{d}t$。

Solve：

第一个导数不是变上限的，因此积分是一个固定值，相当于对常数求导，$\frac{\mathrm{d}}{\mathrm{d}x}\int_a^b\frac{1}{\sqrt{1+x^2}}\mathrm{d}x = 0$。

第二个导数利用公式即可： $$ \frac{\mathrm{d}}{\mathrm{d}x}\int_{\sqrt{\ln x}}^x e^{-t^2}\mathrm{d}t = e^{-x^2} - \frac{1}{2x^2\sqrt{\ln x}} $$

例题

设函数 F(x) = ∫abf(t)|x − t|dt  (a < x < b)，其中 f(t) 连续，求证：F″(x) = 2f(x)。

Solve： $$ \begin{align} &F(x) = \int_a^bf(t)|x-t|\mathrm{d}t = \int_a^xf(t)(x-t)\mathrm{d}t + \int_b^xf(t)(x-t)\mathrm{d}t \\ &= x\int_a^xf(t)\mathrm{d}t - \int_a^xtf(t)\mathrm{d}t + x\int_b^xf(t)\mathrm{d}t - \int_b^xtf(t)\mathrm{d}t \end{align} $$

$$ \begin{align} &F'(x) = \int_a^xf(t)\mathrm{d}t + xf(x) - xf(x) + \int_b^xf(t)\mathrm{d}t + xf(x)- xf(x) \\ &= \int_a^xf(t)\mathrm{d}t + \int_b^xf(t)\mathrm{d}t \end{align} $$

F″(x) = f(x) + f(x) = 2f(x)

例题

$\lim\limits_{x\to\infty}\frac{(\int_0^xe^{t^2}\mathrm{d}t)^2}{\int_0^xe^{2t^2}\mathrm{d}t}$

Solve：

运用 L’Hospital 定理即可 $$ \lim\limits_{x\to\infty}\frac{(\int_0^xe^{t^2}\mathrm{d}t)^2}{\int_0^xe^{2t^2}\mathrm{d}t} = \lim\limits_{x\to\infty}\frac{2e^{x^2}\int_0^xe^{t^2}\mathrm{d}t}{e^{2x^2}} = \lim\limits_{x\to\infty}\frac{\int_0^xe^{t^2}\mathrm{d}t}{e^{x^2}} = \lim\limits_{x\to\infty}\frac{e^{x^2}}{2xe^{x^2}} = 0 $$

定积分的计算方法

对称性与周期性求定积分

  • 设函数 f(x) 在 [−l, l] 上连续且可积，则：
    • f(x) 是奇函数时，∫−llf(x)dx = 0。
    • f(x) 是偶函数时，∫−llf(x)dx = 2∫0lf(x)dx。
  • 设函数 f(x) 在一段区间 [α, α + T] 上连续且可积，f(x) 的周期是 T，那么 ∫αα + Tf(x)dx = ∫0Tf(x)dx。
  • 可以利用函数的对称性解决问题，如果无法注意到对称性可以令 x = a + b − t 发现对称性。
    • f(a + b − x) = −f(x)，称为 f(x) 关于 $(\frac{a+b}{2}, 0)$ 奇对称，∫abf(x)dx = 0。
    • f(a + b − x) = f(x)， 称为 f(x) 关于 $x=\frac{a+b}{2}$ 偶对称，$\int_a^bf(x)\mathrm{d}x = 2\int_{\frac{a+b}{2}}^bf(x)\mathrm{d}x$。
  • 若 f(x), g(x) 在区间 $[\frac{1}{a}, a]$ 上有连续的区间代换，$f(x)=f(\frac{1}{x})$，$g(x)+g(\frac{1}{x})=A$，直接可以令 $t = \frac{1}{x}$，当作一个对称代换处理。

注意：利用对称性，尤其是奇对称性可以大幅简化问题，要注意运用。

Wallis 公式

$$ \int_0^\frac{\pi}{2}\sin^mx\mathrm{d}x = \int_0^\frac{\pi}{2}cos^mx\mathrm{d}x = \left\{\begin{flalign}&\frac{(m-1)!!}{m!!}\cdot\frac{\pi}{2},\;\;m为偶数 \\&\frac{(m-1)!!}{m!!},\;\;m为奇数\end{flalign}\right. $$

这个结论可以直接运用，简化计算流程。

定理

Wallis 公式： $$ \int_0^\frac{\pi}{2}\sin^{2n-1}x\mathrm{d}x < \int_0^\frac{\pi}{2}\sin^{2n}\mathrm{d}x < \int_0^\frac{\pi}{2}\sin^{2n+1}x\mathrm{d}x $$

定积分的应用

平面图形的面积

  • 直角坐标系下的面积公式：

    当曲线 y = f(x) 在 [a, b] 上连续且可积时，已知由曲线 y = f(x)，x 轴以及直线 x = a, x = b 所围成的曲边梯形的面积为： A = ∫ab|f(x)|dx 注意：这里有绝对值，要把原函数分为小区间解决。

    若图形由连续曲线 y = f1(x), y = f2(x) 以及直线 x = a, x = b 围成，面积为： A = ∫ab|f1(x) − f2(x)|dx 若图形由连续曲线 x = φ1(y), x = φ2(x) 以及直线 y = a, y = b 围成，面积为： A = ∫ab|φ1(y) − φ2(y)|dy

  • 极坐标下的面积公式：

    曲线 r = f(θ) 与两条射线 θ = α, θ = β 所围成的图形的面积公式： $$ A = \frac{1}{2}\int_\alpha^\beta r^2\mathrm{d}\theta = \frac{1}{2}\int_\alpha^\beta f^2(\theta)\mathrm{d}\theta $$ 注意：实际图形的旋转过程中要去掉重叠部分，计算实际走过的角度，还要掌握实际图形的对称性。且这里是按照逆时针旋转图像的。

  • 参数方程下的面积公式：

    闭合曲线 x = φ(t), y = ψ(t)  (t0 ≤ t ≤ T) 围成的图像的面积公式： $$ A=\frac{1}{2}\int_{t_0}^T(\psi'(t)\varphi(t) - \varphi'(t)\psi(t))\mathrm{d}t $$

平面曲线的弧长

  • 直角坐标系下的弧长公式：

    若曲线弧由方程 y = y(x)  (a ≤ x ≤ b) 给出，且 y′(x) 在这个区间上连续，则曲线弧是可求长的。

    弧长微分公式： $$ \mathrm{d}s = \sqrt{\mathrm{d}x^2 + \mathrm{d}y^2} $$ 对应的弧长公式： $$ s = \int_a^b\sqrt{1+(y'(x))^2}\mathrm{d}x $$

  • 参数方程表示的曲线：

    若曲线弧由方程 x = φ(t), y = ψ(t)  (α ≤ t ≤ β) 给出，且函数 φ(t), ψ(t) 在这个区间上有连续的导数 φ′(t) ≠ 0，则曲线弧是可求长的，对应的弧长公式： $$ s = \int_\alpha^\beta\sqrt{(\varphi'(t))^2 + (\psi'(t))^2}\mathrm{d}t $$

  • 极坐标方程表示的曲线：

    若曲线弧由极坐标方程 r = f(θ)  (α < θ < β) 给出，且 f′(θ) 在这个区间上连续，则曲线弧是可求长的，对应的弧长公式： $$ s = \int_\alpha^\beta \sqrt{f^2(\theta)+(f'(\theta)^2)}\mathrm{d}\theta $$

横截面积计算立体体积

介于平面 x = a, x = b 之间的立体，若立体被垂直于 x 轴的平面截下的平面面积 S(x)  (a ≤ b) 为已知的连续函数，则立体的体积为： V = ∫abS(x)dx

旋转体的体积

  • 绕 x 轴旋转：

    考虑连续曲线 y = f(x)，直线 x = a, x = b 以及 x 轴所围成的曲边梯形绕 x 轴旋转一周而形成的旋转体，其横截面积为 S(x) = πy2 = πf2(x)，体积为： V = ∫abπy2dx = ∫abπf2(x)dx

  • 绕 y 轴旋转：

    同样地，此时横截面积为 S(x) = π((x + Δx)2 − x2) = π(2x + Δx)Δx，体积为： V = 2π∫abxf(x)dx

旋转体的侧面积

  • 参数方程给出的旋转体侧面积：

    设定义在 [a, b] 上的曲线 x = φ(t), u = ψ(t)  (α ≤ t ≤ β)，而曲线的起点 A = (φ(α), ψ(α))，终点 B = (φ(β), ψ(β))。若函数 φ(t) 与 ψ(t) 在 [α, β] 上具有连续的导数且 φ′(t)ψ′(t) ≠ 0，则上述旋转体的侧面积为： $$ P = 2\pi\int_\alpha^\beta|\psi(t)|\sqrt{(\varphi'(t))^2 + (\psi'(t))^2}\mathrm{d}t $$

  • 直角坐标系给出的旋转体侧面积：

    设曲线 y = f(x)，曲线的起点 A = (a, f(a))，终点 B = (b, f(b))，则侧面积公式： $$ P = 2\pi\int_a^b|y|\sqrt{1+(f'(x))^2}\mathrm{d}x $$

广义积分

无穷积分

定义

无穷积分：设函数 f(x) 定义在无穷区间 [a, +∞) 上，而且对任意 b > a， 函数 f(x) 在 [a, b] 上可积，对变上限的函数 ∫abf(x)dx，如果极限 $$ \lim\limits_{b\to+\infty}\int_a^bf(x)\mathrm{d}x $$ 存在，就记该极限为 ∫a+∞f(x)dx 并称它是 f(x) 在无穷区间 [a, +∞) 上的无穷积分或第一类广义积分，即 $$ \int_a^{+\infty}f(x)\mathrm{d}x = \lim\limits_{b\to+\infty}\int_a^bf(x)\mathrm{d}x $$ 此时称无穷积分收敛，否则称无穷积分发散，当无穷积分收敛时，函数 f(x) 在区间 [a, +∞) 上广义可积，简称可积。

对于无穷积分依然可以使用 Newton-Leibniz 公式，但是相应的要换成极限。

定义

Cauchy 主值：设 f(x) 在 (−∞, ∞) 上有定义，如果 ∫−b0f(x)dx 与 ∫0bf(x)dx 对任意的 b > 0 都存在，则称极限（如果存在） $$ \lim\limits_{b\to+\infty}(\int_{-b}^0f(x)\mathrm{d}x + \int_0^bf(x)\mathrm{d}x) = \lim\limits_{b\to+\infty}\int_{-b}^bf(x)\mathrm{d}x $$ 是无穷积分 ∫−∞+∞f(x)dx 的 Cauchy 主值，记为 $$ \mathrm{V.P.}\int_{-\infty}^{+\infty}f(x)\mathrm{d}x = \lim\limits_{b\to+\infty}\int_{-b}^bf(x)\mathrm{d}x $$ 此时称无穷积分 ∫−∞+∞f(x)dx 在 Cauchy 主值的意义下收敛，简称 Cauchy 主值积分收敛，如果上述极限不存在，就说无穷积分 ∫−∞+∞f(x)dx 在 Cauchy 主值的意义下发散，简称 Cauchy 主值积分发散。

如果 Cauchy 主值积分发散，则无穷积分必发散，但反之不为真。

瑕积分

定义

瑕积分：设函数 f(x) 在区间 (a, b] 上有定义且在点 a 的任意小的右领域内无界，但对 ∀ϵ ∈ (0, b − a)，函数 f(x) 在区间 [a + ϵ, b] 上可积，如果极限 $$ \lim\limits_{\epsilon\to0^+}\int_{a+\epsilon}^bf(x)\mathrm{d}x $$ 存在且有限，则称无界函数的积分或瑕积分 ∫abf(x)dx 收敛，并记为 $$ \int_a^bf(x)\mathrm{d}x = \lim\limits_{\epsilon\to0^+}\int_{a+\epsilon}^bf(x)\mathrm{d}x $$ 否则称该瑕积分发散，点 a 叫做积分的瑕点。

定义

Cauchy 主值：f(x) 在 [a, b] 的内点 c 附近无界，不含 c 的子区间上可积，极限 $$ \lim\limits_{\epsilon\to0^+}(\int_a^{c-\epsilon}f(x)\mathrm{d}x+\int_{c+\epsilon}^bf(x)\mathrm{d}x) $$ 存在有限，称为 ∫abf(x)dx 的 Cauchy 主值，记为 $$ \mathrm{V.P.}\int_a^bf(x)\mathrm{d}x = \lim\limits_{\epsilon\to0^+}(\int_a^{c-\epsilon}f(x)\mathrm{d}x+\int_{c+\epsilon}^bf(x)\mathrm{d}x) $$ 同样的定义有 Cauchy 主值积分收敛与发散。

微分方程的基本概念

其他的概念在线性代数里接触了，主要说一下什么是线性的微分方程和什么是齐次的微分方程

定义

n 阶微分方程可以表示为一个多变量函数方程 F(x, y(x), y′(x), ⋯, y(n)(x)) = 0 其中这个函数 F(x, y, z1, ⋯, zn) 是关于其变量 (y, z1, ⋯, zn) 的线性函数，而其系数仅为 x 的已知函数，则微分方程称为线性微分方程，否则称它为非线性微分方程，n 阶线性微分方程可以表达为 y(n)(x) + an − 1(x)y(n − 1)(x) + ⋯ + a1(x)y′(x) + a0(x)y(x) = f(x) 其中系数 an − 1(x), ⋯, a0(x) 和右端的 f(x) 是已知函数。当右端项 f(x) = 0 时，称之为齐次线性微分方程，否则称为非齐次线性微分方程。

一阶微分方程的解法

变量分离方程

形如 $$ \frac{\mathrm{d}y}{\mathrm{d}x} = y'(x) = g(x)h(y) $$ 的方程，称为变量分离方程。处理方式为 $$ \begin{align} \frac{1}{h(y)}\mathrm{d}y &= g(x)\mathrm{d}x \\ \int \frac{1}{h(y)}\mathrm{d}y &= \int g(x)\mathrm{d}x \end{align} $$ 注意如果存在常数 $\overline{y}$ 使得 $h(\overline{y}) = 0$，则把常值函数 $y = \overline{y}$ 代入，如果条件满足需要补充上这个特解。

一阶齐次方程

形如 y′(x) = f(x, y) 的方程且 f(x, y) 为零次齐次函数，即对于 ∀t ≠ 0 都有 f(tx, ty) = f(x, y) 成立，则微分方程为齐次方程。可以通过变换将其化为变量分离方程，例如令 y = xu(x)，则 y′ = u + xu′，代入方程得到 $$ u' = \frac{\varphi(u) - u}{x} $$ 成为变量分离方程，继续求解即可。

可化为齐次方程的方程

形如 $$ \frac{\mathrm{d}y}{\mathrm{d}x} = f(\frac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2}) $$ 设 a1, b1, a2, b2 不全为零，记 $A = \begin{pmatrix}a_1 & b_1 \\ a_2 & b_2\end{pmatrix}$

  1. det A ≠ 0 时

    当 c1 = c2 = 0 时，函数 $f(\frac{a_1x+b_1y}{a_2x+b_2y})$ 是零次齐次函数，对应的微分方程就是一个一阶齐次方程。

    当 c1, c2 不全为零时，做变量的平移代换 x = ξ + h, y = η + k，则原方程化为 $$ \frac{\mathrm{d}\xi}{\mathrm{d}\eta} = f(\frac{a_1\xi+b_1\eta+a_1h+b_1k+c_1}{a_2\xi+b_2\eta+a_2h+b_2k+c_2}) $$ 选择 h, k 得到非齐次线性方程组 $$ \begin{pmatrix}a_1 & b_1 \\ a_2 & b_2\end{pmatrix}\begin{pmatrix}h \\ k\end{pmatrix} = \begin{pmatrix}-c_1 \\ -c_2\end{pmatrix} $$ 化为一阶齐次方程 $$ \frac{\mathrm{d}\xi}{\mathrm{d}\eta} = f(\frac{a_1\xi+b_1\eta}{a_2\xi+b_2\eta}) $$

  2. det A = 0 时

    则 A 中的行向量线性相关。

    当 a2, b2 都不为零时，设 $\frac{a_1}{a_2}=\frac{b_1}{b_2}=\lambda$，改写原方程为 $$ \frac{\mathrm{d}y}{\mathrm{d}x} = f(\frac{\lambda(a_2x+b_2y)+c_1}{a_2x+b_2y+c_2}) $$ 设函数 z(x) = a2x + b2y(x)，则 z′(x) = a2 + b2y′(x)，方程化为 $$ \frac{\mathrm{d}z}{\mathrm{d}x} = a_2 + b_2f(\frac{\lambda z+c_1}{z+c_2}) $$ 这是一个变量分离方程。

    当 a2, b2 只有一个为零时，设 a2 = 0, b2 ≠ 0，则 a1 = 0，方程化为 $$ \frac{\mathrm{d}y}{\mathrm{d}x} = f(\frac{b_1y+c_1}{b_2y+c_2}) $$ 这是一个变量分离方程。

    当 a2 = b2 = 0 时，只要令 z = a1x + b1y 即可有 z′ = a1 + b1y′，方程化为 $$ \frac{\mathrm{d}z}{\mathrm{d}x}=a_1+b_1f(\frac{z+c_1}{c_2}) $$ 这是一个变量分离方程。

一阶线性方程

形如 y′(x) + p(x)y(x) = f(x) 的方程称为一阶线性微分方程

首先考虑一阶齐次线性微分方程，即 y′(x) + p(x)y(x) = 0 这是一个变量分离方程，解得 yh(x) = Ce−∫p(x)dx

此后利用凑微分法或者常数变易法求解，这里介绍常数变易法。

将常数因子变为函数因子 C(x) yh(x) = C(x)e−∫p(x)dx 代入原微分方程中得到 C′(x)e−∫p(x)dx = f(x) 解得 C(x) = ∫f(x)e∫p(x)dxdx + C 带入得到 y(x) = (∫f(x)e∫p(x)dxdx + C)e−∫p(x)dx

Bernoulli 方程

形如 $$ \frac{\mathrm{d}y}{\mathrm{d}x} + P(x)y = Q(x)y^n\;\;\;\;(n\neq 0, 1) $$ 的方程被称为 Bernoulli 方程，y = 0 是原方程的一个特解。y ≠ 0 时，方程两端同时除以 yn，化为 $$ y^{-n}\frac{\mathrm{d}y}{\mathrm{d}x} + P(x)y^{1-n} = Q(x) $$ 令 u = y1 − n，则 $\frac{\mathrm{d}u}{\mathrm{d}x} = (1-n)y^{-n}\frac{\mathrm{d}y}{\mathrm{d}x}$，原方程化为 $$ \frac{\mathrm{d}u}{\mathrm{d}x} + (1-n)P(x)u = (1-n)Q(x) $$ 利用线性方程求解的方法求出 u(x) 后得到 y(x)。

可降价的二阶微分方程

不显含未知函数的二阶微分方程

形如 y″(x) = f(x, y′(x)) 的方程，做变量代换 p = y′(x)，化为一阶微分方程 p′(x) = f(x, p(x)) 利用一阶微分方程的求法求解即可。

不显含自变量的二阶微分方程

形如 y″ = f(y, y′) 的方程，做变量代换 p = y′(x)，则有 $$ \frac{\mathrm{d}^2y}{\mathrm{d}x^2} = \frac{\mathrm{d}p}{\mathrm{d}x} =\frac{\mathrm{d}p}{\mathrm{d}y}\cdot\frac{\mathrm{d}y}{\mathrm{d}x} = p\frac{\mathrm{d}p}{\mathrm{d}y} $$ 化为 $$ p\frac{\mathrm{d}p}{\mathrm{d}y} = f(y, p) $$ 这是一个一阶微分方程。

二阶线性微分方程的解空间的结构

Wronski 行列式

定理

Wronski 行列式：函数 y1(x) 和 y2(x) 在区间 (a, b) 上线性相关的必要条件是 $$ W[y_1, y_2](x) = \begin{vmatrix}y_1(x) & y_2(x) \\ y_1'(x) & y_2'(x)\end{vmatrix} = 0 $$ 在区间 (a, b) 上成立。

Liouville 定理

定理

Liouville 公式：函数 y1(x) 和 y2(x) 是二阶齐次线性微分方程在区间 (a, b) 上的两个解，则其 Wronski 行列式 W(x) = W(x0)e−∫x0xp(t)dt 其中 x0 是 (a, b) 上的任意固定点。

定理

Liouville 定理：函数 y1(x) 和 y2(x) 是二阶齐次线性微分方程在区间 (a, b) 的两个解，则 y1(x) 和 y2(x) 在区间 (a, b) 上线性无关的充要条件是其 Wronski 行列式处处不为零。

二阶非齐次线性微分方程的解的结构

设函数 y1(x) 是齐次线性方程的一个非零解，则函数 $$ y_2(x) = y_1(x)\int \frac{1}{y_1^2(x)}e^{-\int p(x)\mathrm{d}x}\mathrm{d}x $$ 是方程的另一个与 y1(x) 线性无关的非零解。

二阶常系数线性微分方程

二阶常系数齐次线性微分方程

形如 y″ + py′ + qy = 0 的方程称为二阶常系数齐次线性微分方程，其特征方程为 λ2 + pλ + q = 0 特征方程的根为微分方程的特征根。

  1. 有两个互异的特征根：

    通解为 yh(x) = C1eλ1x + C2eλ2x

  2. 有实的重根 $\lambda = -\frac{p}{2}$：

    方程的一个非零特解为 $y_1(x) = e^{-\frac{p}{2}x}$，另一个非零特解为 $y_2(x) = e^{-\frac{p}{2}x}\int e^{px}e^{\int p\mathrm{d}x}\mathrm{d}x = xe^{-\frac{p}{2}x}$。

    通解为 $$ y_h(x) = C_1y_1(x) + C_2y_2(x) = (C_1 + C_2x)e^{-\frac{p}{2}x} $$

  3. 有共轭的复根：

    设这一对共轭的复根为 λ1 = α + iβ, λ2 = α − iβ。

    则取 eλ1x = eαx(cos βx + isin βx),  eλ2x = eαx(cos βx − isin βx) 则 $$ \begin{align} y_1(x) = \mathrm{Re}(e^{\alpha+i\beta}) = e^{\alpha x}\cos\beta x \\ y_2(x) = \mathrm{Im}(e^{\alpha+i\beta}) = e^{\alpha x}\sin\beta x \end{align} $$ 通解为 yh(x) = C1y1 + C2y2 = eαx(C1cos βx + C2sin βx)

二阶常系数非齐次线性微分方程

形如 y″ + py′ + qy = f(x) 且 f(x) ≠ 0，称为二阶常系数非齐次线性微分方程。

这种方程先求其齐次形式的通解 yh(x)，再得到非齐次方程的一个特解 yp(x)，得到非齐次方程的通解 y(x) = yh(x) + yp(x)。

下面讨论其特解 yp(x)。

  1. f(x) = Pn(x) 是 n 次多项式

    1. 当 λ = 0 不是特征根，令特解 yp(x) = Qn(x) 是 n 次多项式 yp(x) = Qn(x) = a0 + a1x + ⋯ + anxn 代入非齐次方程解出待定系数，得到特解 yp。

    2. 当 λ = 0 是单重特征根，令特解 yp(x) = xQ(x)。

    3. 当 λ = 0 是双重特征根，可以直接将方程积分两次，也可以令特解 yp(x) = x2Q(x)。

  2. f(x) = Pn(x)eαx(α ≠ 0)

    1. 当 α 不是特征根，yp(x) = Qn(x)eαx。
    2. 当 α 是单重特征根，yp(x) = xQn(x)eαx。
    3. 当 α 是双重特征根，yp(x) = x2Qn(x)eαx。

  3. f(x) = Pn(x)eαxcos βx 或 f(x) = Pn(x)eαxsin βx，此时设 f(x) = Pn(x)eαx + iβx，再分出实部与虚部。

    1. 当 α + iβ 不是特征根时，yp(x) = Qn(x)eαx + iβx，其中 Qn(x) 时复系数 n 次多项式，然后分出实部和虚部。
    2. 当 α + iβ 是特征根时，yp(x) = xQn(x)eαx + iβx。

Euler 方程

形如 x2y″ + pxy′ + qy = f(x) 的方程称为 Euler 方程，化为标准形式 $$ y'' + \frac{p}{x}y' + \frac{q}{x^2}y = 0 $$ 令 x = et (x > 0) 或 x = −et (x < 0)，即 t = ln|x| 得到 $$ \begin{align} &y'(x) = \frac{\mathrm{d}y}{\mathrm{d}t}\frac{\mathrm{d}t}{\mathrm{d}x} = \frac{1}{x}\frac{\mathrm{d}y}{\mathrm{d}t} \\ &y''(x) = \frac{\mathrm{d}}{\mathrm{d}x}(\frac{1}{x}\frac{\mathrm{d}y}{\mathrm{d}t}) = -\frac{1}{x^2}\frac{\mathrm{d}y}{\mathrm{d}t} + \frac{1}{x}\frac{\mathrm{d}^2y}{\mathrm{d}t^2}\frac{\mathrm{d}t}{\mathrm{d}x} = \frac{1}{x^2}(\frac{\mathrm{d}^2y}{\mathrm{d}t^2} - \frac{\mathrm{d}y}{\mathrm{d}t}) \end{align} $$

原方程化为 $$ \frac{\mathrm{d}^2y}{\mathrm{d}t^2} + (p - 1)\frac{\mathrm{d}y}{\mathrm{d}t} + qy = f(\pm e^t) $$ 这是常系数线性微分方程，求解即可。
