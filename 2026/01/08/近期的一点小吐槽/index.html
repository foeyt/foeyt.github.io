近期的一点小吐槽

发表于 2026-01-08 分类于 不吐不快 本文字数： 528 阅读时长 ≈ 2 分钟

不吐不快系列第一期

也是停更了有一段时间了，之前的好多 //todo 还没来得及加更（😓），翻看我半年前写的 C 语言代码和写的文章，感觉自己像是个唐氏儿，再加上最近一直在犯唐病（比如人在合肥点了个安庆的外卖），期中考试考崩了之后一蹶不振，一度需要 AI 来为自己做心理医生，现在希望期末不会崩，还有在我写这篇文章的时候颈椎病又犯了，你什么时候能消停！

Hexo 的 LaTex 支持水平可以更上一层楼

我写了这么多字，觉得 Hexo 的 LaTex 公式显示简直就是依托！这显示问题把人难受死了，经常写作十分钟，调整 LaTex 两小时。Hexo 可以学习下 Typora 的公式支持，当然我这里不是在夸 Typora，我写了篇长文章才知道这玩意儿有多卡，这些浏览器套壳的软件简直了。

Steam 库中新增差点全成就和上百小时时长的游戏

《死亡搁浅导剪版》还剩两个成就，《剑星》也差一些成就，《博德之门3》游玩时间突破了一百小时，这些没啥说的，好游戏，好玩！😊

决定向 GitHub 和 Blog 里面扔一点更长的代码

我的 GitHub 也是不负众望好久没看了，Blog 里面的唐氏代码有太多了（大部分都是半年前写的），决定引进优秀代码，提高下 Blog 的整体水平。其实是为了凸显我这半年代码写的明显更加拟人了。

等待寒假，准备前往北京，以及 iGEM 的培训

没啥说的，1月23日或24日离校去北京看亲戚，在我 AI 爹的帮助下也是成功过了 iGEM 面试，希望接下来一切顺利。还有寒假还得准备研讨课的小组作业（😟）。虽然返校宣讲因为本人的极度社恐没有过，但是回高中吹牛逼还是可以的。
